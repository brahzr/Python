1- create an environment:
conda create -n name_env python=version
2- activate the environment:
conda activate name_env / conda deactivate name_env
3-List all environment:
conda env list
4- Delete the environment:
conda env remove -n name_env 
5- Install requirements:
pip install -r requirements.txt
